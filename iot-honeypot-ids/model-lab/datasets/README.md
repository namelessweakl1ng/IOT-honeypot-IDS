# Datasets

Versioned session-level datasets.

| Version | Source                            | Notes                                   |
|---------|-----------------------------------|------------------------------------------|
| v1      | `model_lab.datasets.bootstrap`    | Clearly labeled SYNTHETIC — for dev      |
| v2      | `model_lab.datasets.from_es`     | Pulled from real Elasticsearch events    |

Each dataset is a single CSV file with columns:

```
session_id, label, label_source, campaign_id, scenario_id, dataset_version,
created_at, <FEATURE_NAMES...>
```

`label_source` is one of:

- `SYNTHETIC` — generated by `bootstrap.py`, never from real captures
- `RULE_ENGINE` — derived from the rule engine on real events
- `MANUAL` — human-labeled via the API or a future UI
- `REAL CAPTURE` — produced by a real attacker run + verified
