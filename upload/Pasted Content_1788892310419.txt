PHASE 63 — FEATURE LEAKAGE
============================================================

Audit the current features.

Features such as:

contains_path_traversal
contains_command_injection
contains_default_credentials

are derived from attack classifications/tags.

This can create label leakage.

For example:

if the feature itself contains:

"contains_path_traversal"

and the target label is:

"path_traversal"

then the model can learn a nearly direct shortcut.

That may explain perfect metrics.

This is academically important.

Determine whether these are:

- valid behavioral observables
- post-classification labels
- rule-derived features

If they leak the target, remove them from the classifier or clearly separate them for rule-engine use.

Do not hide this problem.
