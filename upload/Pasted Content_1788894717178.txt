============================================================
THE PROBLEM
============================================================

The current interface does NOT look like a serious cybersecurity
honeypot / intrusion detection / SOC / security telemetry application.

It currently looks like a generic modern SaaS dashboard.

I specifically dislike:

- excessive rounded cards
- excessive border radius
- gradients
- glowing gradients
- giant rounded containers
- soft SaaS-style cards
- excessive empty space
- decorative UI
- oversized typography
- excessive pills
- "pretty" dashboard aesthetics that reduce information density
- generic startup-dashboard styling

The current design needs to be completely audited and brought into
the visual language of:

CYBERSECURITY
SOC
NETWORK SECURITY
INTRUSION DETECTION
HONEYPOT TELEMETRY
TERMINAL / NETWORK OPERATIONS
SECURITY ANALYSIS

Think:

security operations console

NOT:

startup analytics dashboard.

============================================================
CRITICAL RULE
============================================================

BEFORE MODIFYING UI:

1. Inspect the existing UI implementation.
2. Inspect every page.
3. Inspect the shared layout.
4. Inspect the design tokens.
5. Inspect the component library.
6. Inspect the CSS/Tailwind configuration.
7. Inspect reusable cards, buttons, badges, tables and charts.
8. Identify where rounded corners and gradients are coming from.
9. Identify duplicated styling.
10. Create a coherent visual direction.
11. THEN implement.

Do NOT just change the Overview page.

Audit the ENTIRE application.

============================================================
