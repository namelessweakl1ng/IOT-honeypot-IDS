  1300→  1300→   honeypot.name
  1301→  1301→
  1302→  1302→E. event is retrievable through FastAPI /events

  1304→  1304→F. session materializer has created a session
  1305→  1305→
  1306→  1306→G. FastAPI /sessions returns that session

  1308→  1308→H. GET /sessions/{id} returns the event timeline
  1309→  1309→
  1310→  1310→I. event_ids in the session correspond to actual event IDs

  1312→  1312→Do NOT pass merely because any old ES document exists.

  1358→  1358→match_all + latest event
